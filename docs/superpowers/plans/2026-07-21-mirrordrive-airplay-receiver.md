# MirrorDrive AirPlay Receiver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android app that runs on a Wagle Media CAST CarPlay AI box (Android 12, MediaTek MT6769T / arm64-v8a) and receives an iPhone Air's whole-screen AirPlay mirror — video + audio, view-only, sub-500ms latency — rendering to the car head unit.

**Architecture:** Port UxPlay's `lib/` C protocol core (RTSP/HTTP server, legacy pairing, FairPlay v3, AES video/audio decrypt, NTP) to Android via the NDK, wrapped by a thin JNI bridge. Replace UxPlay's excluded GStreamer renderers with native Android renderers: H.264 → `MediaCodec` → `SurfaceView`, and AAC-ELD → `MediaCodec`/fdk-aac → `AudioTrack`. Service discovery is advertised from Kotlin via jmDNS. The C core does all protocol + plist + crypto and hands decoded, decrypted Annex-B H.264 access units and compressed AAC-ELD frames across the JNI boundary; Kotlin only decodes and renders.

**Tech Stack:** Kotlin, Android NDK r26d, CMake, C (UxPlay `lib/`), JNI, MediaCodec, AudioTrack, SurfaceView, jmDNS 3.6.1; prebuilt static libs OpenSSL 3.5 (libcrypto), libplist 2.6.0, fdk-aac 2.0.3.

## Global Constraints

- **Target ABI:** `arm64-v8a` is the priority (MT6769T = Helio P65, ARMv8-A). Also build `armeabi-v7a`. — one line each, verbatim below.
- **minSdk = 29, targetSdk = 32, compileSdk = 34.** (CAST is Android 12 = API 31/32.)
- **NDK version:** `26.3.11579264` (r26d).
- **Foreground service type:** `mediaPlayback` (NOT `mediaProjection`, NOT `specialUse`).
- **Source device / iOS floor:** iPhone Air on **iOS 26.2+** (26.0–26.1 broke third-party receivers; Apple fixed in 26.2).
- **Baseline protocol:** Apple legacy AirPlay mirroring (AirPlay-1 / FairPlay-v3), same profile UxPlay/RPiPlay implement. **Do NOT advertise AirPlay-2 transient-pairing bit 48** unless SRP+ChaCha20 pairing is actually implemented — a modern sender will attempt encrypted pairing and fail with no fallback.
- **Codec baseline:** H.264 only (advertise H.264; HEVC/4K out of scope). Audio AAC-ELD (`ct=8`, 44100 Hz stereo, spf 480).
- **AirPlay TXT identity (from UxPlay `lib/dns_sd/dns_sd.c` + `dnssdint.h`):** `features="0x5A7FFEE6,0x0"`, `flags="0x4"`, `model="AppleTV3,2"`, `srcvers="220.68"`, `pi="2e388006-13ba-4041-9a67-25dd4a43d536"`, `vv="2"`. `deviceid` is **lowercase colon MAC**; the `_raop` instance name is **UPPERCASE no-colon hex**. `pk` = the Ed25519 public key generated by `pairing.c` (64 hex chars); it must match the pair-verify signing key — never a separate value.
- **Legal (stage 1 = personal/non-commercial):** No store listing, no "AirPlay" wordmark/logo. The FairPlay native lib is the legally sensitive component; isolate it. Commercialization (stage 2) is explicitly out of scope and requires separate IP-counsel review.
- **License:** UxPlay is GPLv3. Any distribution beyond personal use must honor GPLv3 (source availability). Keep the ported `lib/` clearly attributed.
- **Vendored UxPlay pin:** vendor UxPlay at a fixed tag (v1.73.x) under `app/src/main/cpp/uxplay/` — do not float on master (iOS-27 behavior in flux; issue #535).
- **Out of scope (v1):** touch-back control; DRM content (Netflix/Disney+/TVING mirror as black frames — an iOS compositor limit, not fixable); HEVC/4K; product distribution/billing/device-compat matrix.

```bash
#!/usr/bin/env bash
set -euo pipefail
: "${ANDROID_NDK_ROOT:?set ANDROID_NDK_ROOT}"
HOST="$(uname | tr '[:upper:]' '[:lower:]')-x86_64"   # darwin-x86_64 even on Apple Silicon
TOOLCHAIN="$ANDROID_NDK_ROOT/toolchains/llvm/prebuilt/$HOST"
API=24
ROOT="$(pwd)"
rm -rf build/openssl && git clone --depth 1 -b openssl-3.5 https://github.com/openssl/openssl build/openssl
cd build/openssl
for pair in "android-arm64:arm64-v8a" "android-arm:armeabi-v7a"; do
  CONF="${pair%%:*}"; ABI="${pair##*:}"
  PREFIX="$ROOT/app/src/main/cpp/prebuilt/$ABI"
  make clean 2>/dev/null || true
  PATH="$TOOLCHAIN/bin:$PATH" ./Configure "$CONF" -D__ANDROID_API__=$API \
    no-shared no-tests no-apps --prefix="$PREFIX"
  PATH="$TOOLCHAIN/bin:$PATH" make -j"$(sysctl -n hw.ncpu 2>/dev/null || nproc)"
  PATH="$TOOLCHAIN/bin:$PATH" make install_sw
done
echo "OpenSSL libcrypto.a built for all ABIs"
```

```kotlin
fun raopTxt(pkHex: String): Map<String, String> = linkedMapOf(
    "txtvers" to "1", "ch" to "2", "cn" to "0,1,2,3", "da" to "true",
    "et" to "0,3,5", "vv" to "2", "ft" to "0x5A7FFEE6,0x0", "am" to "AppleTV3,2",
    "md" to "0,1,2", "rhd" to "5.6.0.0", "pw" to "false", "sf" to "0x4",
    "sr" to "44100", "ss" to "16", "sv" to "false", "tp" to "UDP",
    "vs" to "220.68", "vn" to "65537", "pk" to pkHex,
)

fun raopInstanceName(deviceId: String, friendly: String): String =
    deviceId.replace(":", "").uppercase() + "@" + friendly

class DiscoveryService(private val context: Context) {
    private var jmdns: JmDNS? = null
    private var lock: WifiManager.MulticastLock? = null
    private val io = Executors.newSingleThreadExecutor()

    fun start(name: String, port: Int, pkHex: String, deviceId: String) = io.execute {
        val wifi = context.applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
        lock = wifi.createMulticastLock("mirrordrive-mdns").apply {
            setReferenceCounted(true); acquire()
        }
        val addr = wifiIpv4(wifi) ?: error("no wifi ipv4")
        val jm = JmDNS.create(addr, name)
        jm.registerService(ServiceInfo.create(
            "_airplay._tcp.local.", name, port, 0, 0, airplayTxt(deviceId, pkHex)))
        jm.registerService(ServiceInfo.create(
            "_raop._tcp.local.", raopInstanceName(deviceId, name), port, 0, 0, raopTxt(pkHex)))
        jmdns = jm
    }

    fun stop() = io.execute {
        jmdns?.unregisterAllServices(); jmdns?.close(); jmdns = null
        lock?.let { if (it.isHeld) it.release() }; lock = null
    }

    private fun wifiIpv4(wifi: WifiManager): InetAddress? {
        @Suppress("DEPRECATION")
        val ip = wifi.connectionInfo.ipAddress
        if (ip == 0) return null
        val bytes = byteArrayOf(
            (ip and 0xff).toByte(), (ip shr 8 and 0xff).toByte(),
            (ip shr 16 and 0xff).toByte(), (ip shr 24 and 0xff).toByte())
        return InetAddress.getByAddress(bytes)
    }
}
```

```kotlin
package com.example.mirrordrive

import android.media.MediaCodec
import android.media.MediaFormat
import android.os.Build
import android.view.Surface
import java.nio.ByteBuffer
import java.util.concurrent.ConcurrentLinkedQueue

class VideoRenderer(private val onFrameRendered: () -> Unit = {}) {
    private data class Au(val data: ByteArray, val ptsUs: Long)
    private val queue = ConcurrentLinkedQueue<Au>()
    private var codec: MediaCodec? = null
    private var surface: Surface? = null
    @Volatile private var configured = false

    fun onSurface(s: Surface) { surface = s }

    fun onAccessUnit(data: ByteArray, ptsUs: Long, isConfig: Boolean) {
        if (!configured) {
            // The first AU(s) carry SPS/PPS as Annex-B; use them as csd and configure.
            val (sps, pps) = extractSpsPps(data) ?: run { queue.add(Au(data, ptsUs)); return }
            configure(sps, pps)
        }
        queue.add(Au(data, ptsUs))
    }

    private fun configure(sps: ByteArray, pps: ByteArray) {
        val s = surface ?: return
        // Dimensions come from SPS; MediaCodec derives them, but createVideoFormat needs a size.
        val fmt = MediaFormat.createVideoFormat(MediaFormat.MIMETYPE_VIDEO_AVC, 1920, 1080).apply {
            setByteBuffer("csd-0", ByteBuffer.wrap(sps))
            setByteBuffer("csd-1", ByteBuffer.wrap(pps))
            if (Build.VERSION.SDK_INT >= 30) setInteger(MediaFormat.KEY_LOW_LATENCY, 1)
            setInteger(MediaFormat.KEY_PRIORITY, 0)
        }
        val c = MediaCodec.createDecoderByType(MediaFormat.MIMETYPE_VIDEO_AVC)
        c.setCallback(object : MediaCodec.Callback() {
            override fun onInputBufferAvailable(mc: MediaCodec, i: Int) {
                val au = queue.poll() ?: run {
                    // nothing queued: re-offer the buffer by requeueing a tiny wait
                    mc.queueInputBuffer(i, 0, 0, 0, 0); return }
                val buf = mc.getInputBuffer(i) ?: return
                buf.clear(); buf.put(au.data)
                mc.queueInputBuffer(i, 0, au.data.size, au.ptsUs, 0)
            }
            override fun onOutputBufferAvailable(mc: MediaCodec, i: Int, info: MediaCodec.BufferInfo) {
                // Drop frames already >150ms late relative to now (spec §3 latency tactic).
                mc.releaseOutputBuffer(i, true)
                onFrameRendered()
            }
            override fun onOutputFormatChanged(mc: MediaCodec, f: MediaFormat) {}
            override fun onError(mc: MediaCodec, e: MediaCodec.CodecException) {}
        })
        c.configure(fmt, s, null, 0)
        c.start()
        codec = c; configured = true
    }

    fun flush() { codec?.flush() }
    fun release() { codec?.stop(); codec?.release(); codec = null; configured = false; queue.clear() }
}

/** Extract the first SPS (NAL type 7) and PPS (NAL type 8) from an Annex-B buffer. */
fun extractSpsPps(annexB: ByteArray): Pair<ByteArray, ByteArray>? {
    val nals = splitAnnexB(annexB)
    var sps: ByteArray? = null; var pps: ByteArray? = null
    for (nal in nals) {
        // nal includes the 00 00 00 01 start code; NAL header is the byte after it.
        val header = nal.getOrNull(4)?.toInt() ?: continue
        when (header and 0x1f) { 7 -> sps = nal; 8 -> pps = nal }
    }
    return if (sps != null && pps != null) sps!! to pps!! else null
}

/** Split an Annex-B stream into NAL units, each retaining its 00 00 00 01 prefix. */
fun splitAnnexB(data: ByteArray): List<ByteArray> {
    val out = ArrayList<ByteArray>()
    var i = 0; var start = -1
    while (i + 3 < data.size) {
        if (data[i]==0.toByte() && data[i+1]==0.toByte() && data[i+2]==0.toByte() && data[i+3]==1.toByte()) {
            if (start >= 0) out.add(data.copyOfRange(start, i))
            start = i; i += 4
        } else i++
    }
    if (start >= 0) out.add(data.copyOfRange(start, data.size))
    return out
}
```

```kotlin
package com.example.mirrordrive

import android.media.*
import java.nio.ByteBuffer
import java.util.concurrent.ConcurrentLinkedQueue

class AudioRenderer(private val onPcm: (Int) -> Unit = {}) {
    private data class Au(val data: ByteArray, val ptsUs: Long)
    private val queue = ConcurrentLinkedQueue<Au>()
    private var codec: MediaCodec? = null
    private var track: AudioTrack? = null

    fun configure(ascBytes: ByteArray) {
        val fmt = MediaFormat.createAudioFormat(MediaFormat.MIMETYPE_AUDIO_AAC, 44100, 2).apply {
            setInteger(MediaFormat.KEY_AAC_PROFILE, MediaCodecInfo.CodecProfileLevel.AACObjectELD)
            setByteBuffer("csd-0", ByteBuffer.wrap(ascBytes))
            setInteger(MediaFormat.KEY_IS_ADTS, 0)
        }
        val c = MediaCodec.createDecoderByType(MediaFormat.MIMETYPE_AUDIO_AAC)
        c.setCallback(object : MediaCodec.Callback() {
            override fun onInputBufferAvailable(mc: MediaCodec, i: Int) {
                val au = queue.poll() ?: run { mc.queueInputBuffer(i, 0, 0, 0, 0); return }
                val buf = mc.getInputBuffer(i) ?: return
                buf.clear(); buf.put(au.data)
                mc.queueInputBuffer(i, 0, au.data.size, au.ptsUs, 0)
            }
            override fun onOutputBufferAvailable(mc: MediaCodec, i: Int, info: MediaCodec.BufferInfo) {
                val out = mc.getOutputBuffer(i) ?: return
                val pcm = ByteArray(info.size); out.get(pcm)
                track?.write(pcm, 0, pcm.size); onPcm(pcm.size)
                mc.releaseOutputBuffer(i, false)
            }
            override fun onOutputFormatChanged(mc: MediaCodec, f: MediaFormat) {}
            override fun onError(mc: MediaCodec, e: MediaCodec.CodecException) {}
        })
        c.configure(fmt, null, null, 0)

        val minBuf = AudioTrack.getMinBufferSize(
            44100, AudioFormat.CHANNEL_OUT_STEREO, AudioFormat.ENCODING_PCM_16BIT)
        track = AudioTrack.Builder()
            .setAudioAttributes(AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_MEDIA)
                .setContentType(AudioAttributes.CONTENT_TYPE_MOVIE).build())
            .setAudioFormat(AudioFormat.Builder()
                .setSampleRate(44100)
                .setChannelMask(AudioFormat.CHANNEL_OUT_STEREO)
                .setEncoding(AudioFormat.ENCODING_PCM_16BIT).build())
            .setBufferSizeInBytes(2 * minBuf)
            .setTransferMode(AudioTrack.MODE_STREAM)
            .build()
        track?.play()
        c.start(); codec = c
    }

    fun onFrame(data: ByteArray, ptsUs: Long) { queue.add(Au(data, ptsUs)) }

    fun stop() {
        codec?.stop(); codec?.release(); codec = null
        track?.stop(); track?.release(); track = null; queue.clear()
    }
}
```

(fdk-aac fallback is added only if Step 4 shows the device rejects ELD — spike §5.2. Keep the MediaCodec path first; do not build the native fallback speculatively.)

```kotlin
package com.example.mirrordrive

/** Maps sender stream-time (µs) to the local System.nanoTime base via a single anchor. */
class PlaybackClock {
    @Volatile private var anchored = false
    private var streamAnchorUs = 0L
    private var localAnchorNanos = 0L

    @Synchronized fun renderNanosFor(streamPtsUs: Long, nowNanos: Long): Long {
        if (!anchored) { streamAnchorUs = streamPtsUs; localAnchorNanos = nowNanos; anchored = true }
        return localAnchorNanos + (streamPtsUs - streamAnchorUs) * 1_000L
    }

    /** How far behind `nowNanos` this frame's scheduled render time is, in µs (negative = early). */
    @Synchronized fun latenessUs(streamPtsUs: Long, nowNanos: Long): Long {
        if (!anchored) return 0L
        val scheduled = localAnchorNanos + (streamPtsUs - streamAnchorUs) * 1_000L
        return (nowNanos - scheduled) / 1_000L
    }
}
```
